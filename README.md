# OBSIDIAN // Matte Black Blazor & Pure CSS Starter

A minimalist, obsidian-grade web application starter built with **C# (.NET 10 Blazor)** and **100% Pure Modern CSS** (zero external CSS frameworks like Bootstrap or Tailwind).

## Features

- **Pure CSS Design System (`wwwroot/app.css`)**:
  - Native CSS Cascade Layers (`@layer reset, tokens, base, layout, components, utilities`)
  - Matte Black & Carbon surface hierarchy (`#070708` void to `#18181e` elevated cards)
  - 12-column responsive Bento Grid architecture
  - Pure CSS interactive states using `:has(:checked)`, `:focus-visible`, and fluid `clamp()` typography
- **Interactive C# Blazor Components (`Components/Pages/Home.razor`)**:
  - Live **Project Preset Switcher** (General Studio, AI Lab, Fintech Vault) so you can adapt the template as soon as you have your project idea
  - Interactive **Quick Idea Prototyper** & live node registry filter

## Getting Started

```bash
dotnet run
```
